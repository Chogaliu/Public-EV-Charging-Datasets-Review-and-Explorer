Public EV Charging Datasets Review and Explorer

A lightweight public entry point for reviewing existing public EV charging datasets by geography, temporal pattern, and session-level field availability. Raw data are not redistributed here; links point back to the original dataset providers.

Station and Load Explorer Map-based station/site/zone view with weekly aggregate, 24-hour profiles, weekday/weekend splits, and behavior pattern labels. Session Dataset Explorer Dataset-level comparison for session records, user IDs, charger IDs, start/end times, energy, duration, pricing, weather, and sample rows.

See the GitHub repository README for original data links, source notes, and citation guidance.
